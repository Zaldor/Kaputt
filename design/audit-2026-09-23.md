## Critical Bugs (Must Fix)

### BUG-1: "New match" from menu doesn't close menu dialog
**Journey:** J11 (New match from menu)  
**Severity:** Critical  
**Evidence:** `j11b-setup-dialog-new-match.png`  
**What happens:** Clicking "New match" in the menu calls `newMatch()` which calls `showStartScreen()`, but the menu dialog remains open on top of the start screen.  
**Expected:** Menu dialog should close before showing start screen.  
**Fix:** Add `$('menu-dialog').close()` at the start of `newMatch()`.

### BUG-2: No way to select bot difficulty from start screen
**Journey:** J3 (Play Solo)  
**Severity:** Critical  
**Evidence:** `j03-solo-game-idle.png` — always shows "COINFLIP" (random bot)  
**What happens:** "Play Solo" button always starts with `random` bot and default settings. The setup dialog with bot selection (Berserker, Guardian, Calculator, Tactician, Oracle, Sage, Grandmaster, LLM) is only accessible via "Play Online" from the start screen.  
**Expected:** Either "Play Solo" opens the setup dialog, or the start screen has a bot selector.  
**Fix:** Change "Play Solo" to open the setup dialog with `mode='human'` pre-selected, or add a bot dropdown to the start screen.

### BUG-3: Leaderboard API returns 503
**Journey:** J12 (Leaderboard)  
**Severity:** High  
**Evidence:** `j12-leaderboard-dialog.png` — "Standings couldn't load." + "Badges couldn't load."  
**What happens:** `/api/leaderboard` and `/api/badges` return 503. D1 database issue.  
**Expected:** Leaderboard should show rankings and badges.  
**Fix:** Investigate D1 database connection. Frontend error handling is correct but messages are too vague.

## Cross-Cutting Findings

### Design System Consistency: 8/10
**Strengths:**
- Consistent use of `.sheet` dialog pattern
- Consistent button styles (`.game-button`, `.small-button`, `.sheet-primary`)
- Consistent color palette (yellow, navy, lavender)
- Consistent typography (Barlow 500-900)
- Consistent border radius (12-26px)
- Consistent shadow treatment (inset gradients)

**Issues:**
- Some buttons lack icons (Export match JSON)
- Some dialogs have different padding
- Choice explanations text is smaller than other body text

### Accessibility: 6.5/10
**Strengths:**
- ARIA labels on all interactive elements
- `aria-live="polite"` for announcements
- Focus outlines visible (3px solid #e75412)
- Keyboard navigable (Tab order is logical)
- Screen reader announcements for game events

**Issues:**
- No keyboard shortcuts documented
- No skip-to-content link
- Focus management in dialogs could improve (trap focus)
- No high-contrast mode
- No reduced-motion respect indicator

**Improvements:**
- Add keyboard shortcut cheatsheet (?)
- Add skip-to-content link
- Implement focus trapping in dialogs
- Add high-contrast mode toggle
- Show system "Reduce motion" status

### Error Handling: 6.0/10
**Strengths:**
- Graceful degradation (3D dice → 2D fallback)
- Clipboard fallback for copy code
- Web Share fallback for invite link
- Offline queue for match uploads
- Connection recovery for remote play

**Issues:**
- Error messages are vague ("couldn't load")
- No retry buttons in error states
- No error codes for debugging
- No error reporting/feedback mechanism

**Improvements:**
- Improve error messages with specific actions
- Add retry buttons in all error states
- Add error codes: "Error 503: Database unavailable"
- Add "Report issue" button in error states

### Performance: 8/10
**Strengths:**
- 3D dice capped at 2× DPR
- Reduced-motion respected
- Idle rendering stops
- Self-hosted fonts/icons (no CDN)
- Minimal JavaScript footprint

**Issues:**
- No lazy loading for non-critical dialogs
- No service worker for offline support
- No image optimization for assets

**Improvements:**
- Lazy load leaderboard/match lab dialogs
- Add service worker for offline play
- Optimize images (WebP with fallback)
